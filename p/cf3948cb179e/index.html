Как меняется работа

Та же неделя промо — другая механика

Сейчас

  • Офферы приходят письмом, разбираешь их вручную и на чутьё
  • ТЗ дизайнеру каждый раз пишется с нуля
  • Макет — около дня в очереди у дизайнера
  • Попытки с ИИ: долго объяснять, коряво, исходник не пересобрать
  • Акция в магазине: адреса, промоутеры, типография, отчёты — по переписке
  • Правила бренда знает один человек

С памятью формата

  • Пересылаешь письмо — получаешь разбор офферов с доводами для КС
  • ТЗ собирается из памяти: аудитория, голос, сезон, запреты
  • Черновые макеты во всех форматах; дизайнер доводит, а не рисует с нуля
  • Исходник слоями: любой дизайнер пересоберёт
  • Акция собирается по шаблону: адресная программа, график, заказ в типографию, отчёт
  • Бренд записан и проверяется автоматически — знание остаётся у формата
